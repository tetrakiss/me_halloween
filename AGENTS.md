# Project workflow

- After each completed user-requested change, increment the application patch version in package.json and the root package versions in package-lock.json. Keep the displayed loading-screen version in public/index.html and public/app.js synchronized, and update cache versions for changed browser assets.
- Verify the change, commit the completed work, and push to origin/main (https://github.com/tetrakiss/me_halloween.git), unless the user explicitly requests otherwise. The user has authorized this ongoing workflow.
