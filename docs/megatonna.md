# Мегатонна: игра на телевизоре

Каталог игр открывается по `/games`, игра «Мегатонна» — по `/games/bomb`. На главном экране приложения ссылок на неё нет.
Нужен браузер телевизора с поддержкой JavaScript и пульт, работающий как мышь.
Интерфейс автоматически подстраивается под доступную область браузера,
сохраняя пропорции 16:9. На экране другой формы появляются поля. Фиксированный
контейнер обрезает невидимую область исходного холста и предотвращает
горизонтальную и вертикальную прокрутку, включая изменение размера окна.

## Раунд

Начальный набор выбирается случайно. Серия состоит из трёх раундов, наборы
идут по кругу. Только победа переводит команду в следующий раунд. После
поражения повторяется текущий раунд с тем же набором. После третьей победы
можно начать новую серию. Каждый раунд длится одну минуту. Провода слева направо: красный, жёлтый, синий,
зелёный, белый. Клик сразу разрезает провод. Лимит ошибок уменьшается: первая попытка игры допускает три ошибки,
второй раунд — две, третий — одну. Достижение лимита завершает раунд.
Правильные ответы для ведущего: набор 1 — синий, 2 — жёлтый, 3 — зелёный.

В «Досье» пять папок на выбор. В первом раунде можно открыть максимум три,
во втором — две, в третьем — одну. Первая открывается бесплатно, вторая
отнимает 20 секунд, третья — 30 секунд. Цена зависит от порядка
открытия, а не номера папки. Перед платным открытием нужно подтверждение.
Повторное чтение бесплатно. Таймер идёт при просмотре досье и подтверждения;
остановить его можно только кнопкой паузы.

Любые три подсказки однозначно определяют правильный провод. Во втором
и третьем раундах информации меньше: команда выбирает папки и использует
выводы из предыдущих раундов. Победа без
ошибок даёт две крышки, с ошибками — одну. После поражения ведущий может
выдать утешительную конфету. При неверном разрезании звучит короткий электрический разряд. Кнопка
«Звук» отключает его; выбор сохраняется в этом браузере. Другие звуки
пока не добавлены.

## Сервер

Игра обслуживается существующим Express-процессом (`npm start`). Отдельный
сервис, база данных или Telegram/Max-вход для телевизора не нужны.
`/game-api/rounds` создаёт серию со случайным набором; поле `previousId`
продолжает серию после победы или повторяет раунд после поражения. `/game-api/rounds/:id` возвращает состояние,
`/game-api/rounds/:id/actions` принимает действия `open`, `cut`, `pause`, `resume`.
Таймер, штрафы, ошибки и ответ проверяет сервер. UUID раунда — секрет доступа
только к этому раунду. Ответ не выдаётся в API; открытые подсказки выдаются
после проверки штрафа. Личные данные детей не собираются.

Раунды хранятся в памяти одного процесса до двух часов бездействия. Перезапуск
сервера сбрасывает текущие раунды. При нескольких экземплярах сервера нужна
привязка запросов к одному экземпляру либо общее хранилище состояний.
API ограничивает число раундов и частоту запросов. Для нового раунда после
потери состояния нужно вернуться к запуску игры.

## Проверка

`npm test` проверяет все сочетания трёх подсказок, таймер, паузу, штрафы,
повторные клики и награды. `npm run check` проверяет синтаксис приложения.

## Добавление новых игр

Карточки каталога задаются массивом `GAMES` в `public/games/games.js`. Добавьте
название, описание, URL и картинку. Каталог показывает до двух игр на странице
и автоматически добавляет крупные кнопки перехода между страницами.
Заглушки «Скоро» не кликабельны. Все изображения включены в приложение;
внешние ресурсы и сборка не требуются.

Индикаторы используют локальный семисегментный шрифт DSEG7 Classic Bold Italic
(v0.46, SIL OFL 1.1), https://www.keshikan.net/fonts-e.html. Лицензия
включена в `public/games/bomb/assets/fonts/DSEG-LICENSE.txt`.

Надписи кнопок используют локальный Oswald Bold с кириллицей
(@fontsource/oswald 5.3.0, SIL OFL 1.1; https://fontsource.org/fonts/oswald/about).
Цвет свечения таймера `#FFB000` подобран по светящимся сегментам утверждённого
изображения. Иконки папки, паузы и бомбы встроены в HTML как SVG.

Провода входят в отверстия разъёмов и сохраняют точки крепления при разрезе.
Синий электрический разряд появляется только после неверного выбора.
На экране поражения используется прозрачная табличка «БАБАХ!» из концепта.

### Фоновое радио
Три MP3, предоставленные владельцем проекта, хранятся локально. Первый трек
выбирается случайно при загрузке, следующие идут по кругу 1→2→3→1. Музыка
начинается после первого клика, продолжается между раундами и отключается
вместе с эффектами кнопкой с колонкой. Настройка сохраняется. При скрытии
страницы музыка приостанавливается, при возвращении продолжается.
